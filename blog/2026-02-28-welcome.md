欢迎来到我的技术博客！

这是一个使用 Docusaurus 构建的静态博客。

## 为什么选择 Docusaurus？

1. **开箱即用的博客功能** - 无需额外配置
2. **支持 MDX** - 可以在 Markdown 中使用 React 组件
3. **优秀的代码高亮** - 内置 Prism 支持
4. **暗色模式** - 自动跟随系统主题
5. **静态站点** - 部署简单，速度快
